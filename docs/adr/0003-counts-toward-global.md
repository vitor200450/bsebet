# Tournaments opt out of Global via Counts Toward Global, not by wiping or Season

Beta and other non-career events must not inflate the **Global Leaderboard** (Mundial) or **Career Points**, or new users start at a permanent disadvantage — but tournament results, Picks, Tournament Leaderboard, and Medals must stay intact. We put a persistent admin flag **Counts Toward Global** on each tournament (default on, reversible). When off: Pick points are excluded from Global and Career Points surfaces; Medals from that tournament are excluded from Global tiebreaks only (profile list and counts still show them); users see a clear notice; only users with activity in a counting tournament appear on Global. We rejected wiping beta points (destroys history), a launch-date cutoff (cannot exclude a specific later tournament), inventing a Season entity for this (out of scope; Global is all-time), and silent exclusion (flag is reusable beyond one beta).
