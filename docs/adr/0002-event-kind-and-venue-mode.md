# Tournament presentation uses Event Kind + Venue Mode, not a single category

Circuit role and how a tournament is staged are different signals (e.g. a Monthly Finals can also be LAN). A flat “category” conflates them and either drops information or explodes UI/template combinations. We model **Event Kind** (admin catalog: optional on a tournament, live Presentation Theme, optional one-shot Event Kind Template of `stages` + `scoringRules`) and **Venue Mode** (required Online | LAN) as separate concepts. Structure is seeded once at create time so each tournament can diverge; presentation resolves live from the kind so catalog theme changes stay coherent. Initial Presentation Themes are the closed set `default`, `qualifier`, `monthly_finals`, `major` — not freeform styling and not a LAN theme (Venue Mode owns that). Series/Season grouping and admin “re-apply template” are explicitly out of this decision’s scope.
